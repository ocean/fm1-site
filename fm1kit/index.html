Framework

FM1Kit

Install firmware on the M-VAVE FM-1 over USB-MIDI, from iOS and macOS.

  • iOS 17.0+
  • iPadOS 17.0+
  • macOS 14.0+
  • Swift 6.1+

Overview

FM1Kit speaks the FM-1's update protocol. It reads .fwsc firmware packages, finds the device, answers its read requests while it stages and writes the new firmware, and checks the device reports the new firmware afterwards. It can also finish an update that was cut off, or one started from USB recovery mode, and back up M-VAVE's open firmware before switching away from it.

From V15, it can install m-bootloader, which adds a recovery menu and the chip's USB download mode. A second library, FM1Rescue, uses download mode from a Mac to back up, restore and write the FM-1's whole flash, whatever firmware is installed.

It sticks to the device: finding and downloading firmwares is left to your app. FM-SWITCH is built on it.

ImportantFM1Kit has been tested on one FM-1 so far, from both a Mac and an iPhone. It isn't affiliated with M-VAVE, and installing custom firmware is at your own risk.

Install the package

Add FM1Kit with Swift Package Manager. Until 1.0, minor versions may change the API, so take 0.4.x fixes but not 0.5.0.

.package(url: "https://github.com/ocean/FM1Kit.git", .upToNextMinor(from: "0.4.0")),

The package has two libraries: FM1Kit for iOS and macOS, and FM1Rescue for download mode, which works on macOS only and is empty on iOS.

Install a firmware

Read the package, check what installing it would do, then install it and follow its progress. Switching to a different firmware can erase the FM-1's projects and samples, so it needs confirming.

import FM1Kit

let package = try FwscPackage(data: Data(contentsOf: fileURL))
let updater = FM1Updater(transport: try CoreMIDITransport(clientName: "My App"))

let check = try await updater.check(package)
let confirmed = check.kind != .switchingFirmware || askToSwitch(from: check.device)

try await updater.install(package, options: InstallOptions(confirmsSwitchingFirmware: confirmed)) { event in
    switch event {
    case .writing(let fraction, _): print("Writing \(Int(fraction * 100))%")
    case .finished(let identity): print("Now running \(identity)")
    default: break
    }
}

// Finish an update that was cut off, or one started in USB recovery mode.
if let identity = await updater.identify(), identity.isLoader {
    try await updater.resume(package)
}

For apps aimed at everyone, InstallProgress folds those events into one bar that never goes backwards, in four stages: getting ready, installing, checking and restarting. FM1Advice(for: error) turns any error into a headline, an explanation, whether the FM-1 is still fine, and one thing to do next. summary() describes the connected FM-1: its firmware's name and version, whether it's waiting part-way through an update, and its USB serial number.

Install m-bootloader

installBootloader(_:events:) installs m-bootloader from its fm1-uboot.fwsc package on an FM-1 running V15, keeping the firmware. With it, holding PLAY while switching on opens a recovery menu, holding REC starts download mode, and the firmware is checked before it starts. FM1Kit can't read the bootloader back over USB-MIDI, so the FM-1's screen confirms it. Installing V15 later puts M-VAVE's bootloader back.

Rescue an FM-1 in download mode

In download mode the FM-1 shows up as a USB disk. Taking it from macOS's disk driver needs root, so apps reach FM1Rescue through a privileged helper. A backup reads the 1 MB flash twice and checks both reads against the chip's CRC-32, and is saved as M-Flasher saves it, so either tool can restore it.

import FM1Rescue

try await updater.enterDownloadMode()  // V15 or Felucca; or hold REC with m-bootloader
let session = try FlashSession(connection: USBDownloadModeConnection.open())
let backup = try session.backUp { print("\(Int($0 * 100))%") }
try backup.write(to: backupsFolder)

let plan = try FlashPlan.restoring(otherBackup, onto: backup)
print(plan.notes, plan.warnings, plan.sectors.count)  // show it, then ask to confirm
try session.write(plan) { print("\(Int($0 * 100))%") }
session.close()  // switch the FM-1 off and on to leave

A FlashPlan restores a backup, installs m-bootloader or M-VAVE's bootloader, or installs a firmware, changing only the 4 KB sectors that differ. Writing checks the flash is still what was read, then checks every change against the chip's CRC-32. Another FM-1's backup never replaces this one's factory data, and nothing is written to flash from another model. If writing stops part-way, don't switch the FM-1 off: restore the backup.

  • structInstallOptions

    Confirms a switch of firmware, or a reinstall of the identity already running.

    An install's events as one bar that never goes backwards, in four stages.

  • structFM1Advice

    Any error in plain words: what happened, whether the FM-1 is fine, and what to do.

  • structFM1DeviceSummary

fm1probe

A Mac command-line tool for checking a setup and watching an install closely. Only install, install-bootloader, restore-voices and the flash- commands write to the device, and backup changes which project open firmware shows while it reads. Each asks you to type YES first, and the flash- commands save a backup before writing.

swift run fm1probe ports                 # list MIDI ports
swift run fm1probe identify              # ask the FM-1 what it's running
swift run fm1probe inspect FILE.fwsc     # a package's identity, size and checksum
swift run fm1probe install FILE.fwsc     # install a firmware
swift run fm1probe backup FOLDER         # back up open firmware's projects and samples
swift run fm1probe install-bootloader fm1-uboot.fwsc  # install m-bootloader from V15
swift run fm1probe download-mode         # ask V15 or Felucca to restart into download mode
sudo .build/debug/fm1probe flash-backup FOLDER  # read the whole flash
sudo .build/debug/fm1probe flash-restore BACKUP.bin FOLDER  # put a backup back
sudo .build/debug/fm1probe flash-install FILE.fwsc FOLDER   # install a firmware in download mode

Recovery

Whenever the FM-1 is in its update loader, whether from USB recovery mode (hold OCT− while switching it on, on firmwares that offer it) or an interrupted update, resume(_:events:) can install a firmware.

Beyond that is the chip's USB download mode, from a computer, which works whatever the firmware. FM1Rescue uses it on a Mac; iPhones and iPads can't. V15 and Felucca can be asked to switch to it, and with m-bootloader installed, holding REC while switching on starts it. m-bootloader also opens its recovery menu by itself when the firmware fails its checks.
