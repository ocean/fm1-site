How an install goes

  1. Step 1

    Choose

    Pick a firmware: synths, grooveboxes and games, each with its own page of pictures and links.

    • V15M-VAVE official
    • ESESTAMPIE
    • AWAmbWave

  2. Step 2

    Before you start

    FM-SWITCH checks the package, and that exactly one FM-1 is connected.

    Switching to a different firmware can erase the FM-1's projects and samples, so it asks first.

  3. Step 3

    Installing

    Keep it plugged in. Nearly there.

    • Getting ready
    • Installing
    • Checking Now
    • Restarting

  4. Step 4

    Done

    FM-SWITCH checks the FM-1 reports its new firmware.

    About 20 seconds for V15, and under 40 for Felucca.

What it does

  • Every firmware in one list

    From the firmware hub, fm1-editor.com and aroum's FM1 Resource Hub, updated every day. Filter by kind, or show only firmwares built from source, and save the ones you like to install without a connection.

  • You can always go back

    M-VAVE's official V15 comes with the app.

  • If it stops

    Your phone stays awake while an install runs. If it stops for any reason, you can carry on where it left off.

  • Free

    Every feature is free. If you'd like to say thanks, there's Ko-fi.

In the app

Under the hood

Native SwiftUI on iPhone, iPad and Mac. Talking to the FM-1 is FM1Kit, an open-source Swift package.

The Mac app will come later, from this site. To try it now, build it from the source on GitHub.

Not affiliated with M-VAVE. Installing custom firmware is at your own risk.

Privacy: FM-SWITCH collects no data.
