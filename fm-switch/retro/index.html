FM-SWITCH

Swap your FM-1's firmware from an iPhone, iPad or Mac.

WHAT IT DOES

Plug the M-VAVE FM-1 into your phone, tablet or Mac with a USB cable, pick a firmware and install it. Switch back whenever you like.

M-VAVE's official V15 comes with the app, so it's always there to go back to.

On M-VAVE's open firmware, SAVE MY FM-1 keeps a copy of your projects and samples first.

FIRMWARE

  • One list of FM-1 firmwares, from the firmware hub, fm1-editor.com and aroum's FM1 Resource Hub, with filters for kinds and for firmwares built from source.
  • Finds each firmware's package on GitHub releases, its project page or M-VAVE's downloads, and checks for newer releases.
  • Saves firmwares on the device, so you can flash without a connection.

FLASHING

  • Checks the package before anything is sent, and that exactly one FM-1 is connected.
  • Asks before switching to a different firmware, which can erase the FM-1's projects and samples.
  • Keeps the screen awake while it writes. If it stops for any reason, CARRY ON finishes the job.
  • Afterwards, checks the FM-1 reports the new firmware.
  • On a Mac, with the FM-1 in download mode, backs up its whole flash and restores it later. Each time, macOS first asks for your password so FM-SWITCH's helper can run as an administrator, then for permission to use the FM-1 as a USB drive.

An install takes about 20 seconds for V15, and under 40 for Felucca.

UNDER THE HOOD

Native SwiftUI on every platform. Talking to the FM-1 is FM1Kit, an open-source Swift package.

Every feature is free. To say thanks, there's Ko-fi.

The iPhone and iPad app is in TestFlight now, and the Mac app is a free download from this page, notarised by Apple. For more, check the FM-1 Discord

Not affiliated with M-VAVE. Installing custom firmware is at your own risk.

Privacy: FM-SWITCH collects no data. The Mac app checks GitHub once a day for a newer release, and that request carries nothing about you or your FM-1.
